# Firebase演習 - Vite版

Firebase + Viteを使用したWebアプリケーション演習用プロジェクトです。

## セットアップ

```bash
npm install
```

## 開発サーバーの起動

```bash
npm run dev
```

ブラウザで http://localhost:5173 を開きます。

## ビルド

```bash
npm run build
```

## プロジェクト構成

```
src/
├── index.html       # トップページ
├── main.js          # メインJS
├── style.css        # 共通スタイル
├── firebase.js      # Firebase設定
├── todo.html/js     # Todo機能
├── user.html/js     # ユーザー管理機能
├── practice-event.html/js    # イベント練習
└── practice-storage.html/js  # Storage練習
```
